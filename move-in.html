Q1怎么拿钥匙？›

拿钥匙前请先确保已支付完押金bond + 第一个月租金。我们不接受当场付款，因为没有刷卡机，同时银行也无法立刻到账。只有收到汇款，我们才能给钥匙。

预约拿钥匙：微信小程序扫码预约，或回复 Property Manager 发送的Welcome Letter邮件附上取钥匙的时间（X月X日 X点–X点），两者选其一就好。

Q2取钥匙当天需要做什么？›

首先你需要确保有本地的手机号，以及已完成电/气 gas/热水连接（冷水我们会帮你连好，网络如果需要帮忙连接，可以提前告知）。

第一，确认押金。交完押金后，我们会把你的押金上交到 RTBA（维州专门保管押金的政府机构）。RTBA 收到押金后会给你发一封 confirmation email，你需要打开邮件，从链接点进去确认，确认后即说明你的押金已到 RTBA。如果取钥匙前完成这一步会省掉你很多时间。注意：如果没找到邮件，可以查看垃圾邮件，或在邮箱搜索RTBA。

第二，查看入住报告。它证明房间已做完退房清洁 + 入住前检查。房间所有肉眼能看到的地方我们都拍了照片留存，有unclean 不干净damage 损坏not working 不工作的地方都在报告中标出。你需要在入住后 5 个工作日内查看报告并仔细对比，把没拍到、遗漏的不干净/损坏/不工作的地方添加进报告。已经拍到的不用重复添加。我们只会以此报告作为存证。这一步是为了把你和前租客的责任划清，未来退房时也能省下很多时间精力。

第三，你需要绑定自动扣款支付租金。步骤指导会以邮件形式发送，如果你准备好银行卡号就可以当场完成。

最后，我们会请你签署一份Key Form，确认你所收到的钥匙及其状态。全部完成后，添加好 Property Manager 的联系方式，就可以取钥匙回家啦。

Q3本人没办法现场办理，可以找人代拿吗？›

可以。你需要把代拿人的ID护照或驾照发给帮你租房的人，并通知代拿人带 ID 以便我们现场对照。同时因为本人需要办理以上手续并签署 Key Form，我们会扣下信箱钥匙，等本人有空时再来办公室办理并拿回信箱钥匙。

Q4什么时候交租金？›

以合同起租日期为准。如起租时间为 2月11日，则为每月 11 号交租金。同时因为你已在拿钥匙前支付过 2.11–3.10 的租金，所以下次交租时间是 3月11日（支付 3.11–4.10 的租金），以此类推。如有特殊调整会单独通知。注意：如果设置的是自动扣款，因为银行过账需要时间，会提早几天扣。

Q5交多少租金？›

以合同为准。如果有室友，可以分开付、一起付、五五分、四六分，只要保证我们最后收到的租金和合同一致即可。

Q6租金交到哪里？›

公司账号，具体可查看签合同时邮件附件的Welcome Letter。建议第一次转完押金和第一个月租金后，把公司账号保存。如果第一次是渠道帮忙支付，请要求 Property Manager 再发送一遍 Welcome Letter。保存好这份 PDF，里面有 PM 的邮箱、手机号，及公寓前台的联系方式。
