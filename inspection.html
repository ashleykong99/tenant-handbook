入住检查

家具、清洁、换家具
🔍
Q1房子里有一些小家具/杂物我不想要，怎么办？›

告知你的 Property Manager 你不想要的东西，并请她发送一份房屋原始报告。这份报告记录了房子在房东出租前的状态。所有非记录在内的家具/杂物，大多情况都为前租客添置，你可以自行处理（通常自行丢弃家具需要丢到公寓 hard rubbish collection 并预约搬家电梯，最好提前和公寓 Building Manager 或前台沟通，PM 对此不负责任）。注意：如有家具更换/房东新添置家具等特殊情况，我们会另行告知。

Q2觉得房子有点脏，房东/前租客可以报销清洁费或安排重新打扫吗？›

所有房屋在交付钥匙前均已做过专业清洁 + 蒸洗地毯。可要求 Property Manager 提供清洁收据证明。

注意，每个人对清洁的标准不一样，我们已经检查完房屋并通过了我们的清洁标准。可能出现的情况：地毯不干净吸出很多灰（羊毛地毯吸出很多毛是正常的），开窗或穿鞋进入会造成藏灰/有头发，床垫有汗渍也比较难避免——特别介意可以自备床垫罩。如果有较明显的台面油渍或床垫大面积污渍，我们会安排清洁返工。

Q3想换个床垫/沙发/别的家具，可以吗？›

我们理解每个人对家具有自己的偏好。如果有强烈更换意愿，请先找到和现家具款式、价格相似度高的产品，发送给 Property Manager 征得同意。得到允许后，请自行安排丢弃（步骤同上）和安排新家具进场（记得和大楼 BM 或前台沟通预约电梯，PM 对此不负责任）。
